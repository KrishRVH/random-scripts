§6 · Operating envelope

Specifications

Architecture, licensing, modalities, reasoning controls, release dates, knowledge cutoffs, and deployment implications.

Deployment implications

Pragmatic interpretation of the published specifications.

OW

Open weights

Qwen3.6 27B (Apache-2.0) and DeepSeek V4 Flash (MIT) support self-managed deployment. Real serving cost is not represented by API token price.

27B

Relative self-hosting practicality

Inference: Qwen’s dense 27.8B footprint is generally easier to deploy than DeepSeek’s 284B-total MoE, despite DeepSeek activating 13B parameters per token.

API

Managed proprietary models

Claude 4 Opus, GPT-5.6 Luna, and Claude Sonnet 5 trade infrastructure control for managed scaling, provider tooling, and proprietary capabilities.

Configuration notes

Details that materially alter production behavior.

L

Luna long-context price step

Requests above 272K input tokens use 2× input and 1.5× output rates under standard pricing.

S5

Sonnet 5 tokenizer transition

The same text may become roughly 1.0–1.35× as many tokens versus older Sonnet models, depending on content.

DS

DeepSeek mode mismatch

There is no public Medium mode. High is used as a proxy; Max measurements are never silently substituted into the selected row.
